# 首都圏 駅力マップ

投資用不動産の検討向けに、首都圏9路線・151駅の「駅の力」を3Dで比較するビューア。

- **高さ** = 1日平均乗降人員（推計）
- **色** = 5年伸び率（2019年度 → 2024年度）
- **操作** = 路線ON/OFF、色の指標切替、高さの線形/平方根切替、倍率、ランキングからのジャンプ、CSV書き出し

`index.html` の1ファイルで完結（データも埋め込み済み）。ブラウザで開くだけで動く。

## 数字の読み方（重要）

1. JR東日本は「乗車人員」しか公表しないため、**乗車人員×2**を乗降人員の推計値として全社共通の物差しにしている。実際の乗降人員とは数％のズレが出る。
2. 集計は**JR東日本とつくばエクスプレスのみ**。東京メトロ・私鉄分は含まない。北千住、柏、船橋、大宮、新宿、綾瀬などは実態よりかなり低く出る。
3. 乗換駅は他線からの乗り継ぎ客を含むため、周辺の居住人口以上に大きく出る。駅前商圏の規模とは別物として見る。
4. 伸び率はコロナ前（2019年度）比。定期利用が戻りきっていないため、都心のオフィス街はマイナス、郊外の住宅地はプラスに振れやすい。全151駅の中央値は約 -7%。
5. 幕張豊砂（2023年開業）と高輪ゲートウェイ（2020年開業）は2019年度実績がないため灰色（比較不可）。
6. TXの2019年度は100人単位の速報値ベース。

## データを更新する

`data.json` を差し替えれば表示も変わる（`index.html` にも同じJSONが埋め込まれているので、両方を更新するか、`index.html` の `<script id="payload">` を `fetch('data.json')` に置き換える）。

1駅あたりのスキーマ:

```json
{
  "n": "柏", "pref": "千葉県", "la": 35.862, "lo": 139.971,
  "lines": ["joban"],
  "jr24": 117042, "jr19": 125490, "tx24": null, "tx19": null,
  "b24": 117042, "b19": 125490, "p24": 234084, "g": -6.7
}
```

`b` = 乗車人員、`p` = 乗降人員（推計）、`g` = 5年伸び率（%）、`null` は比較不可。
